# World screenshot assets

Place administrator-approved Celenas Minecraft screenshots in `public/world/`.
Use descriptive, lowercase filenames and prefer optimized WebP or AVIF images
with landscape compositions.

After adding an image, add its relative public path, meaningful alt text, and
approved caption to `gallery.images` in `src/content/home.ts`. Do not add stock
images or images that imply an unconfirmed server feature.
